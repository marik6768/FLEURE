# FLEURÉ Portfolio

Дизайнерский русскоязычный лендинг цветочной студии для портфолио, с editorial-типографикой в духе TT Ricordi Marmo.

## Реализовано
- адаптивный desktop / tablet / mobile интерфейс;
- burgundy hero → плавный strawberry-milk каталог;
- 8 букетов и локальные изображения;
- рабочая корзина;
- изменение количества и удаление;
- формальная страница оформления заказа;
- выбор доставки;
- демонстрационное подтверждение;
- плавные, лёгкие CSS-анимации;
- `prefers-reduced-motion`;
- все изображения локальные, без внешних CDN.

Откройте `index.html` или запустите через Live Server.


### Типографика
Основной display-шрифт — Bodoni Moda, выбран как близкая веб-доступная альтернатива TT Ricordi Marmo: высокий контраст штрихов, тонкие засечки и fashion-editorial характер.
