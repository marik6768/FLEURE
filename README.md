# FLEURÉ

Портфолио-лендинг цветочного магазина, сделанный как демонстрационный e-commerce интерфейс.

## Реализовано
- адаптивный desktop / tablet / mobile дизайн;
- editorial hero с локальным изображением;
- 8 локальных реалистичных цветочных изображений;
- рабочая корзина;
- изменение количества и удаление товаров;
- формальная страница оформления заказа;
- выбор доставки: курьер / самовывоз;
- валидация контактной формы браузером;
- демонстрационное подтверждение заказа;
- отдельная информационная страница о FLEURÉ;
- плавные CSS-анимации и IntersectionObserver без тяжёлых scroll-анимаций;
- поддержка prefers-reduced-motion;
- все изображения хранятся локально в `assets/`.

## Запуск
Откройте `index.html` напрямую или запустите через Live Server / любой простой локальный HTTP-сервер.
