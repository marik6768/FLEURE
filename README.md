# FLEURÉ

Портфолио-лендинг цветочного магазина.

## Запуск
Откройте `index.html` в браузере или используйте Live Server в VS Code.

## Реализовано
- адаптивный desktop / tablet / mobile дизайн;
- editorial hero;
- 8 букетов в евро;
- рабочая демонстрационная корзина;
- изменение количества и удаление товаров;
- демонстрационное оформление заказа;
- hover и scroll-анимации;
- русский интерфейс.

Фотографии подключены через Unsplash как временные внешние ассеты. Для финальной версии портфолио их можно заменить на единый набор реалистичных фотографий букетов с подходящей лицензией.
