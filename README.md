# FLEURÉ — Real Photo Editorial

Портфолио-лендинг цветочной студии, переработанный под реальные фотографии из исходного архива.

## Что изменено
- вся палитра под реальные фото: пудровый розовый, клубничный, винный и кремовый;
- hero перестроен вокруг фотографии `hero`;
- карточки коллекции используют реальные букеты и квадратную композицию без неуместных кропов;
- блок «О нас» повторяет яркий розовый фон фотографии;
- блок доставки использует глубокие винно-зелёные оттенки из фотографии тюльпана;
- типографика целиком построена на Bodoni Moda, близком по характеру к TT Ricordi Marmo;
- кнопки и ссылки получили тонкую editorial-стилистику и плавные hover-состояния;
- исправлен путь к третьей фотографии (`bouquet-3.webp`);
- добавлены webp-копии фотографий для более быстрой загрузки без заметной потери качества;
- корзина, изменение количества, оформление заказа и мобильное меню сохранены рабочими.

Откройте `index.html` или запустите через Live Server.
